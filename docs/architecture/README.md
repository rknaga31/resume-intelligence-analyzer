# Architecture Decision Records

This directory contains ADRs (Architecture Decision Records) documenting significant design decisions made in this project.

## Format

Each ADR is a markdown file named `ADR-NNNN-short-title.md` with the following sections:

- **Status**: Proposed | Accepted | Deprecated | Superseded
- **Context**: The situation that motivated the decision
- **Decision**: What was decided
- **Consequences**: Results and trade-offs
